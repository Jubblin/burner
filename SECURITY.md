# Security policy

## Supported versions
Only the latest released version (and `main`) receives security fixes. Burner is pre-1.0.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private vulnerability reporting:
**Security tab → "Report a vulnerability"** on https://github.com/Jubblin/burner.
If that is unavailable, open a minimal public issue asking for a private contact channel (no details), and the maintainer will respond there.

## Response targets
- Acknowledgement: within 5 days.
- Initial assessment: within 14 days.
- Fix or mitigation for confirmed high/critical issues: aim for 30 days.

## Supply chain
Releases ship a CycloneDX SBOM and `SHA256SUMS`. See RELEASING.md ("CI security checks") for the checks that run on every change.
